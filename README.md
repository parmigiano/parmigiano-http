# Parmigiano HTTP

HTTP backend for Parmigiano Chat (auth-server, http-server, NSFW, profanity).

**Start the stack from [parmigiano-infra](https://github.com/parmigiano/parmigiano-infra), not from this repository.**

```bash
# repos as siblings: parmigiano-infra, parmigiano-http, parmigiano-tcp
cd parmigiano-infra
make up ENV=dev
```
